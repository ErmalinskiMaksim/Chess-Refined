# Description
A minimalistic chess game in C++ and RTWgui.\
Runs on Windows and Linux.

## How to run?
``` bash 
# fetch
git clone https://github.com/ErmalinskiMaksim/Chess-Refined.git
# build
cd Chess-Refined
cmake -S . -B build
cmake --build build
# run
build/Chess/Chess
```
